# Task Manager Full Stack Project

## Overview
A full stack Task Manager web application developed using Flask, SQLite, HTML, CSS, and JavaScript.

## Features
- User Registration & Login
- Session Authentication
- Add Tasks
- Delete Tasks
- Update Task Status
- Todo / In Progress / Done workflow
- Dark Mode
- Task Search
- User-specific task handling

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- Flask

### Database
- SQLite

## How to Run

```bash
pip install flask
python app.py
```

Open:
```text
http://127.0.0.1:5000
```
